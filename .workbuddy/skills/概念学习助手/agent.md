# Agent（智能体）

## 概念解释
Agent 是指能够自主感知环境、做出决策并执行行动的系统。简单来说，Agent 就像一个有目标、能自己想办法完成任务的"数字员工"。

## 核心机制
- 感知：获取环境输入
- 决策：分析信息，选择行动
- 执行：采取行动改变环境

## 应用场景
自动驾驶、智能客服、游戏NPC

## 使用边界
Agent 的能力受限于训练数据和计算资源，不能真正理解世界。

## 我的理解
- 学了这个概念之后，我发现 Agent 其实就是把"感知-决策-执行"这个循环用程序实现了。它不像人类那样有意识，但它能根据设定的目标，在给定环境里自动找最优路径。我觉得它的核心价值在于"自主性"，也就是不需要人实时指挥。
